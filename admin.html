Save all pending changes and push to GitHub. Cloudflare Pages auto-deploys within ~30 seconds.

How publishing works

When you click "Publish", the admin writes your changes to content.json in your GitHub repository (bokle-ai/studio-logan). Cloudflare Pages detects the commit and rebuilds your live site at studiologan.in automatically — no FTP, no manual upload.
